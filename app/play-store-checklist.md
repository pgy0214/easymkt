# 구글플레이 등록 준비 자료

이지리뷰 앱을 구글플레이에 올리기 위해 필요한 것들을 정리했어요. **1번(개발자 계정 등록)은
본인인증·결제가 필요해서 Claude가 대신 할 수 없어요** — 직접 진행해주셔야 해요. 2번부터는
바로 복사해서 쓰실 수 있게 초안을 준비했습니다.

---

## 1. 구글플레이 개발자 계정 등록 (직접 진행 필요)

1. https://play.google.com/console 접속 → 기존 구글 계정으로 로그인 (없으면 새로 만들기)
2. 계정 유형 선택
   - **개인**: 본인 신분증으로 인증 (더 간단, 빠름)
   - **조직(사업자)**: 사업자등록번호로 인증하는데, 2023년부터 **D-U-N-S 번호**(던스넘버, 던앤브래드스트리트 발급)가 추가로 필요해짐 — 조직으로 하실 거면 D-U-N-S 번호부터 미리 신청해두는 게 좋음(무료, 발급에 며칠~몇 주 걸릴 수 있음)
3. 등록비 **$25 (1회, 카드결제)**
4. 개발자 이름(스토어에 표시됨), 주소, 연락처 입력
5. 본인/사업자 인증 — 심사에 며칠 걸릴 수 있음
6. 승인되면 콘솔에서 "앱 만들기"로 새 앱 등록 시작 → 여기서부터 아래 자료들을 입력하면 됨

**참고**: 계정당 앱을 여러 개 올릴 수 있어서, 나중에 스토어(easymkt) 앱도 같은 계정에 올리면 됨.

## 4. 데이터 안전(Data Safety) 섹션 — 콘솔 입력용 요약

Play Console의 "데이터 보안" 설문에 이 내용을 기준으로 답하면 됩니다 (실제 문항은 콘솔에서
세부적으로 나뉘어 있어서, 아래는 항목별 요약이에요):

| 데이터 유형 | 수집 여부 | 수집 항목 | 용도 |
|---|---|---|---|
| 개인 정보 | 수집함 | 이름, 전화번호, 이메일(선택), 생년월일(선택) | 계정 기능, 앱 기능 제공 |
| 재무 정보 | 수집함 | 계좌번호(정산용) | 앱 기능 제공(수당 지급) |
| 사진 | 수집함(선택적) | 리뷰 인증 사진, 사업자등록증(광고주) | 앱 기능 제공 |
| 앱 활동 | 수집함 | 작업 신청/제출 이력 | 앱 기능 제공, 분석 |

공통 답변:
- **제3자와 공유하나요?** 아니오 (법적 요구 시 제외)
- **전송 중 암호화되나요?** 예 (HTTPS)
- **사용자가 삭제 요청할 수 있나요?** 예 (마이페이지 또는 문의를 통해)
- **데이터가 자발적 제공인가요?** 예 (회원가입 시 사용자가 직접 입력)

## 5. 콘텐츠 등급 설문 — 예상 답변

콘텐츠 등급은 국제등급연합(IARC) 설문으로 자동 산정돼요. 이지리뷰는 업무용 도구라 대부분
"해당 없음"으로 답하면 됩니다:

- 폭력성/공포/도박/성적 콘텐츠: 전부 **없음**
- 사용자 생성 콘텐츠(리뷰 텍스트 등 다른 사용자가 볼 수 있는 콘텐츠): **없음** (제출한 리뷰 인증은
  관리자만 확인, 다른 사용자에게 노출 안 됨 — 실제로 맞는지 한 번 확인 필요)
- 위치 공유: **없음**
- 예상 등급: **전체 이용가**

## 6-1. "앱 관련 정보 입력" 체크리스트 답변 모음

Play Console "앱 설정 완료" 안의 개별 항목들이에요. 위에서 이미 답한 개인정보처리방침·데이터
안전·콘텐츠 등급·카테고리 말고, 나머지 항목은 이렇게 답하면 됩니다.

### 앱 액세스 권한 (로그인 정보)
> "모든 기능을 사용하려면 로그인해야 함" 선택 → **테스트 계정의 아이디/비밀번호 입력**

이 서비스는 리뷰어 포털에 전화번호 SMS 인증 **또는** 아이디+비밀번호로 로그인할 수 있어요
(SMS는 비밀번호를 잊었을 때 재발급용). 구글 심사팀은 SMS를 받을 수 없으니까, **아이디+비밀번호로
로그인 가능한 테스트 계정**을 만들어서 그 정보를 여기 입력하면 돼요.

→ **필요한 것**: 리뷰어 포털에 테스트용 계정 하나를 만들고(직접 회원가입하거나, 관리자 화면에서
생성), 그 아이디/비밀번호를 Play Console에 입력. (기존 실제 리뷰어 계정을 심사팀에 주는 건
권장 안 함 — 테스트 전용 계정을 새로 만드는 게 안전함)

## 7. 아직 없는 것 (제가 만들 수 없거나, 실제 확인이 필요한 것)

- **스크린샷** (최소 2장, 폰 기준 권장 4장 이상): 폰에서 앱 실행하면서 캡처한 화면 필요.
  로그인 화면, 오픈풀 목록, 작업 상세, 마이페이지 등 대표 화면 위주로
- **기능 그래픽** (1024×500 배너 이미지): 원하시면 로고 기반으로 만들어드릴 수 있음 — 말씀해주세요
- **개인정보처리방침 최종 확정**: 위 3번 초안에서 회색 표시 부분 채우기
- **사업자 정보**: 개발자 계정을 조직으로 만드실 경우 사업자등록번호, D-U-N-S 번호 등
